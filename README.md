# aml-sentinel
Plateforme de lutte anti-blanchiment (LCB-FT) sur 5 M de transactions : pipeline batch (dbt, Airflow, PostgreSQL), analyse de graphe Neo4j, modèle LightGBM expliqué par SHAP pour réduire les faux positifs des règles métier, outil d’investigation Streamlit et scoring temps réel des transactions (Kafka, Redis, FastAPI)
